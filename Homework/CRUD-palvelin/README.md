# Kotitehtävä 1
## index.js:
### post()
- Lisää pelaajalistaan uuden pelaajan
### get(players) 
- Hakee pelaajalistan
### get(player)
- Hakee pelaajan tiedot annetusta kohdasta
### put()
- Korvaa pelaajan uudella pelaajalla annetussa kohdassa
### patch()
- Päivittää pelaajan tiedot annetussa kohdassa annetuilla parametreilla
### delete()
- Poistaa pelaajan annetusta kohdasta
